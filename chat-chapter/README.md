# Chat chapter prototype

Plays the opening of Operation COPY/WRITE as a text-message thread. Static site, no build; open `index.html` through any local server.

Story text lives in `story.js`, colours in `theme.css`. Portraits and node art are crops of public-domain paintings (Arnolfini Portrait, Girl with a Pearl Earring, Sunflowers, The Kiss, The Scream, The Starry Night).
